Project: SIIA Backend (Django)

Summary

This repository contains the backend for the SIIA project, implemented with Django and Django REST Framework.

Key points
- Python: requires Python 3.13 or later (see `pyproject.toml`).
- Frameworks: Django, Django REST Framework, Simple JWT for authentication.
- Database: configured for MySQL via environment variables.
- Container: A `Dockerfile` is included and uses `uv` to install dependencies and run the Django server.
